# 3DFractals

A real-time Mandelbox and distance-estimator fractal explorer built with SDL2, OpenGL, and GLSL, extending Jan Kadlec's Boxplorer 1.02 with Catmull-Rom keyframe splines, stereoscopic/panoramic capture, and a parameter editor powered by AntTweakBar.


See [Architecture](architecture) for how it fits together.
